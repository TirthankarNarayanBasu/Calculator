# Calculator

A simple browser-based calculator built with HTML, CSS, and vanilla JavaScript.

## Features

- Addition, subtraction, multiplication, and division
- Clear button to reset the display
- Expression evaluation in the browser
- No external dependencies or build step

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Use the calculator buttons to enter an expression and select `=` to calculate it.

## Project Structure

```text
Calculator/
├── index.html   # Calculator layout and controls
├── style.css    # Calculator styling
├── script.js    # Calculator behavior
└── README.md    # Project documentation
```

## Usage

- Select `C` to clear the current expression.
- Select number and operator buttons to build an expression.
- Select `=` to display the result.
- Invalid expressions or non-finite results display `Error`.
